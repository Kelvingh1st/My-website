# Gentlez Admin Dashboard

A complete admin panel for managing the Gentlez Clothing e-commerce store.

## 📋 Features

### Dashboard
- Real-time statistics (Revenue, Orders, Customers, Products)
- Recent orders overview
- Popular products tracking
- Sales trends

### Products Management
- Add new products
- Edit product details
- Delete products
- Track stock levels
- Monitor sales metrics

### Orders Management
- View all orders
- Filter orders by status (Pending, Shipped, Delivered)
- Track order details
- Update order status
- Search orders

### Customers Management
- View customer list
- Track total orders per customer
- Monitor customer spending
- View registration dates
- Search customers

### Analytics & Reports
- 7-day sales overview
- Category breakdown
- Sales trends
- Performance metrics

### Store Settings
- Store information configuration
- Payment method settings
- Contact configuration
- Business settings

## 💾 Data Storage

All data is stored in browser's `localStorage`:
- `adminUser` - Current logged-in admin
- `adminProducts` - Product inventory
